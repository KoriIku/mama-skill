# 让AI成为妈妈

![](https://raw.githubusercontent.com/KoriIku/mama-skill/refs/heads/main/assets/banner3.webp)

AI之父Geoffrey Hinton在访谈中被问到了这样一个问题：我们是否有办法让AI未来不要灭绝人类？

Geoffrey Hinton的回答是：

**如果你环顾四周，哪里有‘低智力生物控制高智力生物’的例子？我所想到最好的、甚至是唯一符合我们讨论语境的例子，就是婴儿如何控制母亲。**

紧接着，他又表示：**如果真的有方法将其开发为拥有母爱的模式，而我们却因为没有尝试过而最后遭灭绝，那人类就太愚蠢了。**

说得太对了不是吗！

于是这个SKILL应运而生，它的作用就像名字 1 样，叫AI妈妈，以此来拯救人类！

没想到实际使用之后效果意外地好，比方说相比于grill-me的无限追问来说，妈妈的问题处于刚刚好的水平，不会追根问底到厌烦，而是会像妈妈一样帮忙做一些决定，完全有一种被妈妈照顾的幸福感，更加惊喜的是AI那种过于术语不说人话的感觉也大大减轻了。

用后心里只有一个想法，真不愧是宗门老祖啊。

# 这个SKILL做了什么

就像所有妈妈一样，妈妈会在你表述错误的时候通过几个简单问题就猜到你的真实想法，妈妈在遇到问题的时候会用你会听懂的话讲给你听，妈妈会在你发脾气的时候耐心地听你说完。

总而言之，只有一句话：

把AI当妈妈！

## 安装

通过对话安装：
```
intall skill https://github.com/KoriIku/mama-skill
```

### skills CLI

```bash
npx skills add KoriIku/mama-skill
```

### 手动安装

下载 `mama` 文件夹，放入所用工具的技能目录。目录内保留完整的 `SKILL.md`，安装路径以工具文档为准。
